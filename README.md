# unknown-unknowns（未知的未知）

一个给 Claude 用的 skill：你说出要第一次做的事，它主动列出**内行默认知道、而你想不到要问的事**，并按踩坑的代价排序。

A Claude skill. Tell it what you are about to do for the first time, and it lists what insiders treat as obvious and newcomers do not know to ask, ranked by what ignorance would cost.

## 它解决什么问题

搜索和问答都需要你先提出问题。但第一次做一件事时，最容易吃亏的恰恰是你不知道存在的那部分。比如第一次租办公室的人，通常想不到要问"这个地址能不能用来注册公司"。

这个 skill 不写入门指南，只做一件事：把你问不出来的问题找出来。

## 输出长什么样

- **假设**：它对你所在地、规模、阶段的推断，一行写清。
- **三个等级的盲区**，共 5 到 9 条：无法挽回的、费钱费时的、知道了更顺的。
- 每一条包含：一句陈述事实的标题、为什么新手想不到、错过的代价、**现在就能做的动作或原话问法**、可信程度（已核实 / 行业惯例 / 因地而异需确认）。
- **行话**：几个能帮你继续搜索的内行术语。
- **该问谁、怎么问**。
- **这份清单没覆盖什么**。

## 安装

Claude Code：

```bash
git clone https://github.com/yangkaiwen2002/unknown-unknowns ~/.claude/skills/unknown-unknowns
```

Claude 桌面端或网页端：下载仓库里的 `SKILL.md`，在"设置 → 技能"中上传。

## 怎么用

直接说你要做的事和你的处境，越具体越好：

- "我们 5 个人准备在杭州第一次租办公室，下周看房，有什么是我不知道该问的？"
- "I'm about to hire my first employee in California. What am I missing?"
- "下周第一次上线带付费订阅的产品，有什么坑是我想不到的？"

## 局限

- 它给的是"该去核实什么、该问谁什么"，不能代替律师、会计师等专业人士对你具体情况的意见。
- 涉及法规、费率、期限的条目会标注可信程度。标着"需确认"的，请务必确认。
- 清单本身一定不完整，所以它每次都会告诉你还应该去问谁。

- 它会联网核实关键条目，所以比直接提问慢。测试中每次约 4 到 5 分钟，是不用 skill 时的两到三倍。

## 验证结果

用三个场景做了两轮测试：杭州租办公室、加州雇第一个员工、首次上线付费订阅。每个场景各跑一次有 skill 和无 skill 的回复，由不知道哪份用了 skill 的独立评审盲评，并联网抽查事实。每个场景每轮只跑了一次，样本很小。

| 场景 | 第一轮 | 第二轮（修改后） |
|---|---|---|
| 杭州租办公室 | 有 skill 小幅胜出 | 有 skill 明显胜出 |
| 加州雇第一个员工 | 有 skill 小幅胜出 | 有 skill 小幅胜出 |
| 首次上线付费订阅 | 有 skill 小幅胜出 | 有 skill 小幅胜出 |

- **事实准确性**：第二轮抽查了有 skill 回复中的 13 条关键论断，全部正确，引用的链接也都支持对应论断。
- **优势在哪**：不用 skill 时，Claude 也能覆盖大部分众所周知的坑。skill 的优势主要是按"不可挽回程度"排序、每条给出可执行的动作和原话问法、标注可信度。评审认为内容广度上两者接近，无 skill 的回复有时更全。
- **已知弱点**：条目上限会挤掉一些法定必办手续（在雇员工场景中出现）。第二轮后加了"法定步骤清单"规则，只在该场景上做了单次复核。
